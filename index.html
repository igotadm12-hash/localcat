what is LOCALCAT?

LOCALCAT is a simple idea: give your project a public-facing network address and a way to make selected services reachable.

01 / PUBLIC IP
A public endpoint for services you choose to host.

02 / PORT CONTROL
Choose the port number and protocol your service needs, subject to provider and network limits.

03 / PROTOCOLS
TCP, UDP, or both. HTTP/HTTPS for web services.

04 / BUILT FOR MAKERS
Useful for personal websites, game servers, APIs, demos, and development projects.

Only publish ports for systems you control, and keep authentication and firewall rules enabled.

PROJECT OVERVIEW

LOCALCAT aims to make hosting your own services easier with a public IP endpoint and configurable port access.


PROTOCOL SUPPORT

Plan for TCP, UDP, dual-protocol configurations, and HTTP/HTTPS web traffic.


NETWORK NOTES

Not every port can be made reachable on every network. Availability depends on provider, firewall, and host configuration.


SAFETY FIRST

Expose only services you own or are authorized to administer. Use strong authentication and restrict access where possible.
